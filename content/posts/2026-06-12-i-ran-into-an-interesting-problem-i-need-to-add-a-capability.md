I ran into an interesting problem: I need to add a capability inside one skill whose purpose is to generate another skill specialized for a specific project. In other words, it is a skill for creating project-specific skills. This is where the bootstrapping process reaches a project-specific fixed point, because the equivalence relation that defines the semantic quotient space cannot be fully generic; it has to be fixed by the domain knowledge of the specific business.
