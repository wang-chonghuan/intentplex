I've been exploring the 'Skill as a Service' concept and decided to take it a step further. I’ve exposed the todoclaw.com chat interface as a skill—called tdcchat skill—available for any agent to call. This allows external agents to directly leverage todoclaw’s internal reasoning and skill set. Essentially, it functions as a communication protocol between agents, using skills as the primary interface.
