We're a Codex team. Everyone built useful skills. Nobody had a clean way to share them. That's why I built SkillHost.

```
pip install skillhost

skillhost add <git-repo>
# clones into ~/.skillhost and symlinks into your agent's skills folder

skillhost update
# pulls latest, everywhere it's linked

skillhost list
# see all skills; mute any without uninstalling
```

Add `--project` to any command to scope it to a single repo instead of your whole machine. User-level skills follow you everywhere; project-level skills stay put.

Works with Codex, Claude Code, and OpenCode, OpenClaw.

No registry, no server — just Git doing what it's good at.
