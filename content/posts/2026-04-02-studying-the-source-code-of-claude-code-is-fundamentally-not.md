Studying the source code of Claude Code is fundamentally not harness engineering. From now on, all core reasoning capabilities will come from systems like Codex or Claude Code. Harness engineering focuses on how to prepare the environment for these reasoning cores.

Most teams are only capable of building wrappers around Codex; attempting to implement their own reasoning engines is not only unnecessary, but often ends up reducing product quality instead of improving it.
